Como inserir o framework tailwind css no seu código?
Coloque o código "https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4" dentro da tag script
Como inserir o alpine.js no seu código?
Coloque o código "https://cdn.jsdelivr.net/npm/alpinejs@3.x.x/dist/cdn.min.js" dentro da tag script
Como inserir o DaisyUI no seu código?
Coloque o código "https://cdn.jsdelivr.net/npm/daisyui@5" rel="stylesheet" dentro da tag script
